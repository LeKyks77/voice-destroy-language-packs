# Language packs 1.1.0

Première publication du catalogue multivariantes pour Voice Destroy 1.5.0.

- Accordéons par langue dans le jeu.
- Modèles `small` et `normal` pour le français et l'anglais américain.
- Descriptions matérielles et mémoire requise affichées avant téléchargement.
- Installation atomique d'une variante à la fois par langue.
- Compatibilité conservée avec les packs 1.0.0 déjà installés, reconnus comme `small`.
